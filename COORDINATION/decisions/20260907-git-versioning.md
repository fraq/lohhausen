# Решение и предложение от 2026-09-07: Добавление проекта в Git

## Инициатор:
`dorner_lead` по прямому поручению пользователя от 2026-09-07.

## Обоснование:
Проект веб-симулятора Лоххаузена достиг зрелой стадии:
- Базовое математическое ядро `src/model.js` и 26 тестов стабилизированы.
- Развернут полнофункциональный Mayoral Cockpit (`src/app.js`), советники и каузальный анализ (`src/causal.js`), адаптивные стили и векторная графика.
- В проекте работают несколько участников (`dorner_lead`, `dorner_analyst`, `debrief_agent`, `agy`).
- Отсутствие системы контроля версий создавало риски неконтролируемой перезаписи файлов и потери истории правок.

В корне проекта уже подготовлен качественный `.gitignore`, исключающий:
- тяжелые бинарные книги (`*.pdf`, `*.djvu`, `*.epub` — свыше 130 МБ);
- системный мусор (`.DS_Store`, `node_modules/`);
- метаданные IDE (`.idea/`, `.vscode/`, `.gemini/`);
- промежуточные артефакты и кэши тестов (`.tdd/`, `artifacts/*.png`, `artifacts/*.json`).

## Принятое решение:
1. Инициализировать локальный Git-репозиторий в корне проекта (`git init`).
2. Зафиксировать базовый коммит (initial commit) со всеми проверенными исходными кодами, тестами, документацией и координационными файлами.
3. Использовать Git для фиксации этапов разработки каждым агентом в пределах назначенных границ записи.
4. Хранилище книг и исходных материалов оставить read-only вне индекса Git согласно правилам `.gitignore`.
