# Выбор моделей помощников

Основание: пользователь разрешил запускать внутренних агентов с разными моделями для экономии ресурсов разработки.

Codex остается руководителем и отвечает за итоговую приемку. Для новых ограниченных подзадач выбирает доступную модель по сложности: экономные варианты для извлечения данных, небольших правок и заданных проверок; более сильные для архитектуры, взаимосвязанной динамики и сложных дефектов. Больше агентов не означает автоматически более выгодное решение.

Доступные в текущем механизме запуска варианты включают gpt-5.6-luna, gpt-5.6-terra, gpt-5.6-sol, gpt-5.5 и gpt-6-astra. Наличие модели при каждом новом запуске проверяется по текущим возможностям инструмента; тарифы этим документом не утверждаются.

Работающего book_review не перезапускаем ради смены модели. Для новых помощников с явным выбором модели используем самодостаточное ограниченное поручение и изолированный контекст. Внешний процесс agy не перенесен в Codex; имя роли не меняет провайдера или доступные модели.
