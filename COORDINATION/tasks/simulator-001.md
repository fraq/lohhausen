# simulator-001 — веб-симулятор Лоххаузена

Owner: codex
Status: done
Основание: прямое поручение пользователя от 2026-09-06; Codex старший, agy помогает.

Цель: изучить предоставленную книгу Дёрнера и создать работающее веб-приложение для управления Лоххаузеном с взаимосвязанной динамикой и разбором последствий решений.
Границы Codex: docs/, src/, public/, tests/, scripts/, корневые файлы приложения и README.md, AGENTS.md, PROTOCOL.md, собственное состояние, эта карточка, новые сообщения/решения. Исследовательские файлы agy не редактировать.
Делегирование: research-001 принята внешним agy, материалы переданы и получили замечания Codex. По последующему запросу пользователя запущен внутренний `/root/book_review`, задача research-internal-001, ACCEPT получен. Внешний agy подтвердил остановку новых команд; основной ход проекта не зависит от подтверждений в его окне.

Критерии: все 11 AC/EC/ERR из подтвержденной docs/simulator-spec.md выполнены. Приложение работает на http://127.0.0.1:4173; повторный запуск — npm start.

Реализация завершена: автономная модель города, русское адаптивное приложение, проекты с задержками, датированные отчеты, дневник, графики, сохранение и итог 120 месяцев. Источники/авторские коэффициенты отделены в документации и интерфейсе.
Делегирование реализации: red_tests (terra) — независимый RED, model_green (terra) — расчет, ui_assets (luna) — SVG/CSS, refactor_review (terra) — независимая проверка. Codex — интерфейс, интеграция, сценарии, браузерная приемка. Все назначенные файлы освобождены после приемки; дальнейшую запись согласует Codex.
Проверка: RED 11 fail → GREEN 11 pass, тесты неизменны; REFACTOR review не потребовал переделок. Финальные npm test/check прошли. Шесть сценариев × 120 месяцев = 720 состояний с проверками баланса, границ и загрузки. Реальный Chrome: полный срок, отчет/проект, сохранение/reload, поврежденная запись, клавиатура и 390px без переполнения. Источники и переписка по HTTP дают 404.
Результат и доказательства: docs/verification.md; docs/model-parameters.md; scripts/verify-scenarios.mjs; artifacts/scenario-results.json.
Следующий шаг: пользовательская игра и обратная связь; обязательных незавершенных работ по первой версии нет. Публичная публикация не входит в задачу.
