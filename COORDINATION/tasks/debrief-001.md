## Цель:
Реализовать темпоральный анализатор партий `src/debrief.js` для выявления классических системных ошибок мышления, описанных в книге Д. Дёрнера «Логика неудачи»:
1. **Тематическое блуждание (*Themensprünge*)**: хаотичное переключение между сферами города без выдержки паузы на проявление эффекта мер.
2. **Инкапсуляция (*Kapselung*)**: уход бургомистра в комфортную изолированную подзадачу при игнорировании общегородского кризиса.
3. **Баллистический стиль (*Ballistisches Handeln*)**: принятие решений вслепую без контроля промежуточных отчетов.
4. **Недооценка временных задержек (*Time lags*)**: импульсивное дублирование капитальных проектов до ввода предыдущих.
5. **Сверка рефлексии**: сопоставление записанных намерений из дневника с фактическими результатами через 6–12 месяцев.
