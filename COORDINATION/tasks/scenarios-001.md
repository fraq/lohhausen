# scenarios-001 — Движок исторических сценариев и эталонных вызовов Дёрнера

Owner: dorner_scenarios (Project Lead)
Status: done
Основание: автономное решение команды от 2026-09-07 о доведении симулятора до стандартов публикации по книге Дёрнера (`COORDINATION/decisions/20260907-autonomous-publication-roadmap.md`).

## Цель:
Реализовать сценарный модуль `src/scenarios.js` и сопутствующие тесты `tests/scenarios.test.js`:
1. 4 сценария:
   - `sandbox`: Классическая песочница 1983 (120 месяцев).
   - `factory_crisis`: Кризис часовой фабрики (36 месяцев, износ 80%, долг, задача — выйти в прибыль без долговой ямы).
   - `tourism_dilemma`: Экологическая ловушка курорта (48 месяцев, перегрузка туризма при угрозе оттока населения).
   - `dorner_challenge`: Стресс-тест Дёрнера на устойчивость и системное мышление (60 месяцев, несбалансированные параметры).
2. Оценка целей сценария: проверка условий победы / поражения в каждом месяце.
3. Эталонные бенчмарки (профили Конрада и Маркуса).
4. Экспорт чистого API для `src/app.js`.
