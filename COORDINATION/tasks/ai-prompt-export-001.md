# ai-prompt-export-001
Owner: dorner_scenarios
Status: done
Priority: High (User direct request)

## Цель:
Реализовать в веб-симуляторе Лоххаузена экспорт итогов партии с готовым научно обоснованным системным промптом для мгновенной отправки в Claude, Gemini, ChatGPT или Codex.

## Выполнено:
1. `src/debrief.js`:
   - Добавлена функция `formatDebriefAIPrompt`: формирует самодостаточный Markdown-документ с системным промптом аналитика когнитивных ловушек (по Дёрнеру и Стерману), итоговыми метриками города, сработавшими индикаторами, хронологией решений и заметок игрока, таблицей динамики по контрольным точкам и вопросами для саморефлексии.
   - Добавлены `buildChessMatchRecord` и `formatDebriefLMN`: шахматная нотация LMN v1.2 для машинного разбора.
2. `src/app.js`:
   - В интерфейс разбора (`debriefView`) добавлены кнопки:
     * `📋 Скопировать промпт для ИИ` (`copy-ai-prompt`): копирует весь промпт с данными в буфер обмена (с fallback на загрузку файла).
     * `🤖 Скачать для ИИ (Markdown + Промпт)` (`export-debrief-ai-md`): загрузка `.md` файла.
     * `🧠 LMN (JSON для ИИ)` (`export-debrief-lmn`): загрузка `.json` файла нотации.
3. `src/locales/extra.js`:
   - Локализация новых кнопок и уведомлений на английский, немецкий и французский языки.
4. `tests/debrief.test.js`:
   - Добавлены модульные тесты для `formatDebriefAIPrompt` и `formatDebriefLMN`. Тестовый набор: 123/123 green.
