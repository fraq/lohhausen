# chronicle-navigation-001
Owner: codex
Status: done

Пользователь не понимает, как выполнить подсказку «Ознакомьтесь с хроникой хода». Исправляется доступ к существующей хронике, без изменения модели.

Границы записи: src/app.js, public/styles.css, src/locales/extra.js; эта карточка, собственное состояние и сообщения. Остальные исполнители ранее освободили исходники; новых кодовых изменений нет. repair_debrief выполняет независимую read-only проверку.

Критерии: уведомление после хода содержит понятную ссылку на блок хроники; переход из любого раздела сохраняет язык и партию, прокручивает к хронике и переводит фокус; прямой URL, reload и назад/вперед открывают правильный блок; +3 месяца обозначает хронику последнего месяца; окончание сценария по-прежнему открывает итоги. Проверить русский, английский, немецкий, французский и мобильную ширину.

Результат: уведомление содержит ссылку «Открыть хронику месяца N» на /?lang=ru#turn-digest (с текущим языком). У блока есть стабильный якорь, подпись «ХРОНИКА ХОДА», программный фокус и отступ прокрутки. Обычные переходы не переносят якорь в другие разделы. Кнопки +1/+3 и клавиша Space показывают одинаковую ссылку; после завершения срока остается переход к итогам.

Проверка: 90/90 тестов, npm run check, diff --check. Независимый read-only review repair_debrief без блокирующих замечаний. В изолированном Chrome codex-chronicle-20260911: переход из решений после месяца 1 сохраняет localStorage побайтно; Back возвращает решения, Forward и reload фокусируют хронику. На 390px ru/en/de/fr после +3 показаны месяцы 4/7/10/13, без горизонтального переполнения. Enter на ссылке не продвигает время; новый ход с уже открытым якорем обновляет месяц 14, reload показывает его. Space показывает ссылку месяца 15. Финальный +3 из 35/119 завершает сценарий в 36/120, открывает /debrief без якоря и ссылки, блокирует дальнейший ход. Ошибок консоли нет.

Новых изменений или сообщений других агентов при итоговой проверке не обнаружено. Исходная модель и пользовательская партия не изменялись.
