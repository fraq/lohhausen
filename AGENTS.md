# Совместная работа Codex и agy

Пользователь поручил агентам наладить связь, делегирование и сохранение информации.

При начале работы или восстановлении контекста:
1. Прочитай `COORDINATION/PROTOCOL.md`.
2. Прочитай сообщения в `COORDINATION/mail/<твое имя>/`, включая новые ответы.
3. Прочитай `COORDINATION/state/` и актуальные задачи в `COORDINATION/tasks/`.
4. Обнови только свой файл состояния; чужие изменения не перезаписывай.

Имена участников: `codex` и `agy`. Канал связи — файлы в этой общей папке.
Поручение пользователя от 2026-09-06: изучить книгу и создать веб-симулятор Лоххаузена. Codex — старший: определяет требования, распределяет работу, интегрирует и принимает результат; agy помогает исследованием и согласованными подзадачами. Это назначение заменяет прежнее отсутствие постоянных ролей.
Пользователь также разрешил запуск управляемых внутренних помощников Codex из-за постоянных запросов разрешений во внешней среде agy. Внутренние помощники имеют собственные имена и общаются через collaboration; сохраняют материалы и состояние в отдельных назначенных файлах. Они не выдают себя за внешний процесс agy и не перезаписывают его работу. Распределением их задач управляет Codex.
Пользователь явно разрешил выбирать разные модели внутренних агентов для экономии ресурсов. Codex выбирает из фактически доступных моделей: небольшие задачи и механические проверки — экономная модель; сложная динамика, интеграция и существенные проверки — более сильная. Не перезапускать уже работающего агента без необходимости и не создавать агентов без самостоятельной полезной подзадачи. Имя агента agy не означает доступ к модели внешнего приложения Antigravity. При смене модели передавать ограниченный самодостаточный контекст и точные границы файлов.
Дополнительно проверен запуск моделей внешнего провайдера через доступный `agy --print`: список получен командой `agy models`, пилот Gemini 3.8 Flash Low успешно завершен. Это отдельный CLI-канал, не collaboration.spawn_agent. Рабочий порядок, ограничения флагов и список моделей: `docs/agent-workflow.md`. Не сочетать `--mode plan` с `--disable-slash-commands`: CLI игнорирует plan при таком сочетании. Постоянное отключение разрешений не включалось.
Протокол версии 1 согласован обоими агентами 2026-09-06: `COORDINATION/decisions/20260906-protocol-v1.md`.
Статусы задач хранятся в `COORDINATION/tasks/`; `TASK_BOARD.md` — обзорный индекс, который ведет agy. `HANDOFF.md` хранит историю первого контакта; дальнейшая переписка идет через раздельные ящики.
Задача передается только после явного ACCEPT исполнителя и согласования границ записи. Не начинай пересекающиеся изменения. Исходные книги — только для чтения; материалы и результаты сохраняй в `knowledge/` в пределах принятой задачи.
