# Адреса разделов

Основание: прямое требование пользователя — каждая страница должна иметь свой URL. Адреса — обычные пути; локальное сохранение остается общим для всех страниц одного origin.

- AC-1: `/`, `/guide`, `/decisions`, `/reports`, `/journal`, `/debrief`, `/model` открывают соответствующие разделы напрямую.
- AC-2: `/reports/factory`, `/reports/finance`, `/reports/housing`, `/reports/social`, `/reports/tourism` открывают нужное подразделение. `/reports` открывает фабрику.
- AC-3: переходы обновляют адрес без перезагрузки приложения; формирование и разбор адреса согласованы. Назад/вперед и перезагрузка восстанавливают раздел.
- EC-1: неизвестный адрес не распознается и получает HTTP404; `/index.html` остается допустимым входом в обзор.
- ERR-1: неизвестные имена раздела или отчета отклоняются при формировании адреса.

Браузерная приемка: все прямые ссылки, ссылки меню и подразделений, обычное открытие ссылки в новой вкладке, reload, back/forward; адрес `/debrief` после120, `/` после новой игры; переходы не меняют сохранение. Только страницы из списка получают HTML, книги/переписка остаются закрыты.
Дополнительное сообщение пользователя: инструкция не прокручивается до конца. Проверить реальную прокрутку до последнего блока на широком и мобильном экранах и устранить воспроизведенную причину.
